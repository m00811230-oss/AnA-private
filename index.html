Firebase & Rules Setup

How to fix "Missing or insufficient permissions":

  1. Open Firebase Console and select your project.
  2. Go to Firestore Database → Rules tab.
  3. Replace the existing rules with this code:
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}

Click Publish in Firebase Rules tab, and messages will sync live instantly across your devices!
